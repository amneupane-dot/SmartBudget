# SmartBudget – Personal Expense and Budget Tracker

**Student:** Amit Neupane  
**Course:** COSC 3506 – Software Engineering

## Project Description

SmartBudget is a web-based application designed to help users manage their income, expenses, and monthly budgets.

The system will allow users to record transactions, set budgets, and view spending analytics.

## Technologies Used

- HTML
- CSS
- PHP
- MySQL
- PDO
- MAMP

## How to Run Locally

1. Install MAMP.
2. Place the project folder inside MAMP's `htdocs` directory.
3. Create a MySQL database named `smartbudget_db`.
4. Create the required database tables.
5. Copy `db.example.php` to `db.php` and update the database credentials.
6. Start MAMP and open the project in your browser.
